#
# 格式：<分支卡号> <对方卡号或 -> <提交sha7..40> <理由，必填>
# 例：t_b5fde972 t_1b200562 52a2f93  W1 的返工卡 t_1b200562 修原卡 P2，同一卡族
#
# 规矩（照抄设计结论，不要放宽）：
# - 新增条目必须写理由；只按提交 SHA 逐条豁免，禁止通配（不支持任何 * / 前缀匹配）。
# - 只能豁免具体提交；不能豁免整条分支、也不能豁免整对卡。
# - 豁免不适用于 checkout 偏移检查。
# - 每次命中都会在输出里回显理由，不会被静默吞掉。
